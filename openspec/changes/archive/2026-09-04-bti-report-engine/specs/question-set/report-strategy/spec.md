## Purpose

Controls which report generation path is used for a given question set, allowing simple sets to keep the existing algorithmic pipeline while advanced sets opt into AI-powered narrative generation.

## ADDED Requirements

### Requirement: Report strategy field

Each question set SHALL have a `report_strategy` field with two valid values: `"algorithmic"` and `"engine"`. The default value SHALL be `"algorithmic"`.

#### Scenario: Default strategy
- **WHEN** a question set is created without specifying `report_strategy`
- **THEN** its `report_strategy` is `"algorithmic"`

#### Scenario: Strategy persists
- **WHEN** a question set's `report_strategy` is set to `"engine"`
- **THEN** all subsequent report generations for sessions using that question set use the engine path

### Requirement: Algorithmic dispatch

When a session's question set has `report_strategy = "algorithmic"`, the system SHALL generate the report using the existing `lib/scoring/` pipeline without calling any external AI service.

#### Scenario: Algorithmic path produces report
- **WHEN** both players have submitted answers and the question set strategy is `"algorithmic"`
- **THEN** the report is generated by the local scoring engine and stored without an Anthropic API call

### Requirement: Engine dispatch

When a session's question set has `report_strategy = "engine"`, the system SHALL first run the existing algorithmic engine to produce the structured report, then pass that output to the AI narrative generator to produce enriched narrative copy.

#### Scenario: Engine path calls AI
- **WHEN** both players have submitted answers and the question set strategy is `"engine"`
- **THEN** the system runs the algorithmic engine, then calls the Anthropic API to generate narrative copy

#### Scenario: Engine path falls back on AI failure
- **WHEN** the Anthropic API call fails
- **THEN** the system stores the algorithmically computed report without narrative enrichment and does not block report delivery

### Requirement: Invalid strategy rejected

The system SHALL reject any `report_strategy` value that is not `"algorithmic"` or `"engine"` at the data layer.

#### Scenario: Unknown strategy value
- **WHEN** a question set is saved with `report_strategy = "magic"`
- **THEN** the database rejects the write with a constraint error
